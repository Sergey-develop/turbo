# Под капотом — Турбо-рейв

Адаптивная реализация предоставленного коллажа на Vue 3, Composition API, TypeScript strict, Vite и SCSS. Код находится в `src/`, оригинальные пользовательские файлы сохранены в родительской папке.

## Запуск

```sh
npm install
npm run dev
```

Открыть адрес, напечатанный Vite. Проверка типов: `npm run typecheck`. Production-сборка: `npm run build`. Предпросмотр сборки: `npm run preview`.

## Реализация

Восемь логических компонентов секций и общая система адаптивных стилей. Семантическая разметка, типизированные данные программы и спикеров, локальный Manrope. Автомобиль переключается при наведении или нажатии, мобильное меню закрывается после перехода по якорю, карточки на телефоне прокручиваются горизонтально. FAQ раскрывается с клавиатуры, календарь скачивается в формате ICS. Учитывается reduced motion.

Форма проверяет обязательные поля, e-mail, номер телефона и согласие на обработку данных. Маркетинговое согласие необязательно. Форма не выполняет сетевую отправку и сообщает об отсутствии серверной интеграции после успешной проверки. Контакты, повторяющиеся имена и темы докладов перенесены из макета как демонстрационные значения.

## Проверки и визуальное сравнение

Проведены четыре итерации полноразмерных скриншотов в Chrome через Playwright на ширинах 1920, 1440, 980, 768 и 390 px. Существующие вырезки коллажа имеют ширины 1920, 1440, 980 и 390 пикселей; экспортные CSS-размеры исходного дизайна не подтверждены. Скриншоты сравнивались с соответствующими областями без масштабирования всей страницы через CSS. Для третьей итерации сохранены наложения 50% и difference-изображения на общую высоту; они диагностические и не означают подтверждённую точность экспорта.

Файлы проверки находятся локально в `qa/`: `iteration-N-WIDTH.png`, `iteration-N.json`, `compare-3-WIDTH.jpg`, `overlay-3-WIDTH.jpg`, `difference-3-WIDTH.jpg`. В Git/публикацию тяжёлые артефакты QA не включены.

Исправлены вертикальное смещение автомобиля, размеры заголовков, неравномерная десктопная сетка спикеров, порядок формы и контактов, положение и размер молнии, карта для планшета и лишние отступы. На 1920 px высота страницы 10054 px против 10088 px у растрового референса; на 1440 — 8550 против 8596; на 980 — 8937 против 8923; на 390 — 6753 против 6733. Эти значения описывают общую геометрию, а не долю совпавших пикселей.

Проверены меню и якоря, переключение капота, раскрытие/закрытие FAQ, ошибки пустой формы, корректные данные, отсутствие POST-запросов, скачивание ICS, прокрутка карточек, reduced motion и сообщение о недоступных документах. Ошибок JavaScript и незагруженных изображений на контрольных ширинах нет. Дополнительно проверено отсутствие горизонтального скролла на 320, 375, 600, 1024, 1200, 1600 и 2560 px.

## Оставшиеся отличия и необходимые исходники

- Это реализация с известными расхождениями, а не подтверждённый Pixel Perfect. Цельный фон гаража за спикерами отсутствует: чистые полосы из коллажа не воспроизводят всю сцену и отражения. Нужен оригинальный фон без наложенных карточек и текста.
- Нужны отдельные экспорты логотипов, увеличенного фрагмента капота, карты и нижней текстуры. Сейчас используются растровые вырезки; резкость и кадрирование отличаются при изменении ширины.
- Шрифт Manrope выбран по указанию пользователя. Отдельные переносы, интервалы, яркость фоновых изображений, размеры портретов и детали FAQ ещё отличаются от коллажа. Для строгой доводки нужны исходные фреймы/Figma с размерами и стилями.
- В коллаже варьируются имена одного портрета и состав текстов карточек. Воспроизведены видимые состояния; для публикации реального мероприятия нужны окончательные данные спикеров и тексты докладов.
- Контакты из макета демонстрационные. Юридические документы не предоставлены; кнопки сообщают об их отсутствии. Сервер регистрации не подключён.
- Время в программе начинается в 14:00, а в первом экране указано 18:30. Оба значения сохранены из макета; календарь использует время первого экрана, 27 ноября 2026 с 18:30 до 00:00 по Москве.
- На телефоне маршрут скрыт, как в мобильной области референса; навигация показывает соответствующее событию имя секции из исходного коллажа («спикеры» над программой).

Для дальнейшей точной доводки достаточно заменить ассеты и уточнить исходные параметры; архитектуру пересоздавать не требуется.
