# 3D-приглашение

Тестовый вход: `/?ar=test`. Без этого параметра открывается обычный сайт.

«Открыть приглашение» запускает 25-секундную анимацию из переданного GLB и последовательность экранов. Финальный экран появляется через 28 секунд. «К мероприятию» и «Перейти на сайт» удаляют только параметр `ar`, сохраняя остальные параметры и якорь.

Модель, фон, анимация и Three.js находятся в `public/ar/`; внешнего CDN нет. `npm run ar:vendor` обновляет локальные модули из установленного Three.js 0.186.1. Дата, время и адрес берутся из CMS сайта. Озвучка использует синтез речи браузера, по умолчанию выключена.

При ошибке WebGL/модели или загрузке дольше 45 секунд доступен переход на сайт. При уменьшении движения в системных настройках показывается собранная машина без анимации. Приближение колёсиком отключено, чтобы модель не выходила за границы кадра.

Это 3D-приглашение по предоставленному примеру. Наложение на камеру телефона и WebXR в исходном демо отсутствуют и здесь не добавлены.
